# Yugal Agarwal — Portfolio

My personal site — part case-study archive, part PM notebook, part poetry corner.

## Features

- **Case-study driven project showcase** — deep dives into work like *VahanSync* (a 0→1 autonomous logistics matchmaking OS), *D2CHealth*, *BMS*, *eDimension*, and a WhatsApp-native marketplace, each with the problem, the approach, and an embedded deck
- **PM Library** — a written library of the frameworks I actually use (RICE, KANO, evaluation metrics, value-vs-complexity, customer journey mapping) with visuals
- **Startup story** — the 0→1 journey, including a UP Government grant and a Shark Tank India run
- **Poetry corner** — a personal side project of English poems, Hindi kavitayein, and shayaris
- Custom animated UI: particle & mesh gradient backgrounds, glass-morphism cards, scroll-reveal and scroll-progress effects, all hand-built (no UI kit)

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS

## Running locally

```bash
npm install
npm run dev
```
